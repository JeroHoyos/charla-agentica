# Para probar

## Recomendar

1. Escriban: Quiero comprar un apartamento. ¿Qué me recomiendas?
2. El chat pregunta lo que falta. Respondan: Unos 400 millones
3. Luego: Tres alcobas, en Laureles, y tengo un perro
4. El chat recomienda los apartamentos que cumplen todo, con el dibujo de cada uno y una fecha para visitarlo.

## Agendar

1. Escriban: Quiero visitar el apartamento 303 el próximo sábado a las 10:00. Me llamo Laura Gil.
2. El chat cuenta las reglas de horario y muestra las fechas libres como botones. La que pidieron sale de primera.
3. Elijan una fecha. Aparece otro cuadro, el human in the loop, que pregunta si están seguros.
4. Con «Ver otra fecha», vuelven las fechas libres para elegir otra.
5. Con «Cancelar», el chat dice que no agendó nada.
6. Con «Sí, agendar», el chat dice que la visita ya está programada.
